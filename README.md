# Reflex-game
Reflex-game is a small test project made in winforms.

## Gameplay
- Click the "start" button
- Wait 3 seconds
- Click it again within 1,1 seconds
- If you click while waiting or if you are late to click it you lose

## Why was this made
This project is for concept showcase only. It is not production-ready as it is missing dependencies and key components, such as the winforms files.
